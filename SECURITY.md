# Security policy

## Supported versions

Only the latest `main` branch and the latest published package versions receive security fixes.

## Reporting a vulnerability

Please use GitHub's private security advisory flow for this repository. Do not open a public issue containing credentials, exploit details, or user data.

When reporting, include the affected version, impact, reproduction steps, and a suggested mitigation if available.

The starter is not safe to expose directly to the public internet without TLS, secret rotation, a durable storage adapter, backups, and an application-level authorization policy.
